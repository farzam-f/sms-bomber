   • پژوهش‌های امنیتی
   روی شماره موبایل خودتان طراحی شده است.

🚫 استفاده از این ابزار برای ارسال پیامک انبوه به دیگران،
   بدون رضایت صریح آن‌ها، مصداق بارز:
   • مزاحمت
   • آزار و اذیت
   • نقض قوانین جرایم رایانه‌ای
   است و پیگرد قانونی دارد.

⛔️ همچنین ارسال درخواست‌های مکرر به سرویس‌هایی مانند:
   دیوار، دیجی‌کالا، اسنپ، تپسی و علی‌بابا،
   نقض شرایط استفاده (ToS) آن‌ها محسوب می‌شود و منجر به:
   • مسدود شدن دائمی IP
   • مسدود شدن شماره موبایل
   • مسدود شدن حساب کاربری
   شما خواهد شد.

⚖️ مسئولیت هرگونه استفاده نادرست از این کد،
   کاملاً بر عهده کاربر است و توسعه‌دهنده هیچ‌گونه
   مسئولیتی در قبال عواقب قانونی یا خسارات ناشی از آن
   نمی‌پذیرد.
